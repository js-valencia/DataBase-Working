## 📌 Acerca del proyecto

**DataBase-Working** es un repositorio académico desarrollado para organizar, documentar y conservar las actividades, ejercicios y prácticas correspondientes a la asignatura de **Bases de Datos**.

El proyecto reúne recursos relacionados con el diseño conceptual de datos, la transformación de modelos entidad-relación en modelos relacionales y la implementación de estructuras mediante el lenguaje SQL.

Su organización permite mantener una separación clara entre los diagramas, los modelos de datos y los scripts de implementación, facilitando la consulta de los trabajos y su utilización como material de estudio.

| Directorio | Responsabilidad |

## ⚙️ Metodología de trabajo

El proceso general de diseño e implementación de bases de datos comprende las siguientes etapas:

1. 🔍 **Análisis de requisitos:** identificación de las necesidades de información del problema planteado.
2. 📐 **Modelado conceptual:** identificación y representación de entidades, atributos y relaciones.
3. 🔗 **Diseño relacional:** transformación del modelo conceptual en tablas y definición de claves.
4. 💻 **Implementación SQL:** creación de estructuras y establecimiento de restricciones de integridad.
5. 📝 **Documentación:** organización y conservación de los archivos generados durante cada actividad.

El procedimiento se adapta a los requisitos específicos de cada ejercicio académico.
